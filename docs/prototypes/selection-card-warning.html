警告出现的条件

  • 仅勾选且尚未确认的数据风险，在所属卡片里显示。
  • 明确隔离、已确认、未勾选、不可导入与已导入项没有风险段落。
  • “应用到草稿”确认当前模式；只返回会保留草稿但不确认。
  • 列表至多一条紧凑数量汇总，不再逐项堆叠黄色 Alert。

动效边界

顶边作为锚点，底边轻轻向下展开；Indicator 随实时高度同步居中。快速反向点击保留当前运动，不等待前一次结束。

主题色取自项目 Palette；当前是 Web 手感原型，不代表 GPUI 或 Linux ARM64 已实现、已验收。可开启辅助线检查六类选择卡片。
