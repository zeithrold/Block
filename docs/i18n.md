# Desktop language

Block supports English (`en`), Simplified Chinese (`zh-Hans`) and Japanese
(`ja`). On the first desktop start it selects the first supported OS language
and stores the concrete choice in the global preferences document. Settings
previews a choice until it is saved; first setup saves its selector immediately.
Restoring General settings selects English rather than detecting the OS again.
Welcome's “Not your language?” entry intentionally stays in English so it is
recognizable before a language is chosen.

Product messages use semantic keys in `crates/block-ui/locales/` and lookups
explicitly name the view's language. Locale resources are version 2 JSON so a
feature's English, Simplified Chinese and Japanese translations stay together.
Keep whole interpolated messages together and pass user data and technical
diagnostics as arguments, without translating their contents. Retained UI
messages must retain their meaning and arguments, not only a rendered string.

The desktop bootstrap bridges the selected language to gpui-component, which
has one process-wide locale. Product views and frozen page transitions keep
their own language; painting a snapshot must not change that global. Tests and
non-desktop consumers do not set a process-wide locale.

## Verification

The integrated implementation passed `just check` on macOS ARM64 and
`python3 scripts/verify-platform.py --platform linux-arm64` on Debian 13 ARM64,
including 450 UI unit tests and three GPUI framework tests. The additional
workspace Clippy check with `--features tracing/log` also passed.

Native KDE/Xwayland checks on Linux ARM64 exercised OS-derived English,
Simplified Chinese and Japanese first paint, persistence before setup completion,
and retaining Japanese when restarted with an English OS-language environment.
The Welcome button, language drawer and Select were exercised with immediate
save; General Settings Select preview, Cancel and Save were checked against
the persisted preference. Tab and Shift-Tab remained inside the language sheet
with its popup open, and standalone synthetic Crash Help rendered all three
languages and closed through Escape. Chinese/Japanese glyphs and the affected
layouts were visually inspected. Captures are retained under the test host's
`block-logging-native-20261030T085846Z/i18n-native/` task directory.

These checks do not establish Windows or macOS native language behavior,
exhaustive visual coverage, real authentication, or Minecraft gameplay.
