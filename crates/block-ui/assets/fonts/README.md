# Inter

Inter Latin font, from @fontsource-variable/inter 5.3.0 in the prototype worktree on 2026-10-21. Converted from WOFF2 to native SFNT/TTF and instanced at weights 400, 500, 600 and 700 with FontTools 4.67.0, so CoreText, DirectWrite and FreeType can select real font weights without depending on variable-axis support. Bundled under the SIL Open Font License in OFL.txt. Other scripts and emoji use operating system fallback. Block does not read Block-UI or invoke conversion tools at runtime or build time.
